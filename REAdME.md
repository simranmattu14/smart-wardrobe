# Smart Wardrobe
A personal wardrobe management web application that allows users to digitally organize their clothing, create outfits, and get personalized styling suggestions.

## About the Project
Users can create an account, add clothing items to their digital wardrobe, organize items using categories and attributes, and clothng pieces to create outfits. The project is being developed as a full-stack application, with a focus on creating a clean, intuitive user experience while learning modern web development, authentication, and database management.

## Features
### Digital Wardrobe
The Digital Wardrobe allows users to add clothing items to their personal wardrobe and upload images of their clothing. Items can be organized and categorized, making it easier for users to keep track of their wardrobe and find specific pieces.

### User Authentication
Smart Wardrobe uses Clerk to provide secure user authentication. Users can create an account, log in, and verify their email address. This allows each user to have their own personalized wardrobe and ensures that their account information remains secure.

### User Interface
The application features a responsive and user-friendly interface built with HTML and CSS. Interactive navigation makes it easy for users to move between different sections of the application, including their wardrobe, outfit creator, and other features.
